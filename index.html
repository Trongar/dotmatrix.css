► dotmatrix.css

Classless pixel-art CSS framework with textures and bevels. Write semantic HTML. Get a retro CRT interface for free. ~5KB gzipped. Zero JavaScript.

► Quick Start

Three ways to install:

CDN

<link rel="stylesheet"
      href="https://unpkg.com/dotmatrix.css/dotmatrix.css">

npm

npm install dotmatrix.css
import 'dotmatrix.css/dotmatrix.css';

Manual

Download dotmatrix.css and link it:

<link rel="stylesheet" href="dotmatrix.css">

Apply a texture

<article data-texture="paper">...</article>
<section data-texture="dots">...</section>
<button data-bevel="out">Raised</button>
