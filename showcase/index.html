◆ The texture system

crt.css ships with 8 textures and 2 bevels. Apply them with a single HTML attribute — no classes, no extra CSS.

◆ What this proves

Each demo overrides only the CSS variables it needs and applies textures via attributes. Zero changes to the framework. Zero new classes. Zero JavaScript.

The textures system follows the same philosophy as the rest of crt.css: semantic, opt-in, zero-cost. The 8 textures + 2 bevels add ~1.2 KB to the framework. They use radial-gradient and repeating-linear-gradient — no extra HTTP requests, no PNG sprites, no JS lazy-loading.

And the bevels? They're a single CSS rule that combines two inset shadows. No images, no border-image, no linear-gradient hacks — just the same border you already have, plus a 1px highlight on one edge and a 1px shadow on the other.
