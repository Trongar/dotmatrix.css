What is crt.css?

A classless CSS framework that turns semantic HTML into a retro pixel-art interface. Just write normal HTML and link the stylesheet.

Why "classless"?

Because you shouldn't need to add class="btn btn-primary" to every button. Your HTML tags already have meaning — let them style themselves.

Can I customize it?

Yes! Override CSS variables on :root or use data-theme="dark" for a built-in dark theme.
